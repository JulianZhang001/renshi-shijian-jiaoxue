# 二年级《认识时间》互动教学资源

这是一个面向小学二年级数学课堂的单文件网页教学资源，用于复习和练习《认识时间》。

## 资源内容

- `index.html`：主教学网页，双击即可在浏览器中打开，也可以部署到 Gitee Pages。

## 教学目标

- 认识钟面上的时针、分针、秒针。
- 理解时针走一大格是 1 时，分针走一小格是 1 分，秒针走一小格是 1 秒。
- 掌握 1 时 = 60 分，1 分 = 60 秒。
- 能根据钟面读出时间，并说出自己的判断过程。

## 功能亮点

- 教师演示：适合课堂投屏讲解，可控制时针、分针、秒针的显示。
- 自由拨钟：学生可以拖动或点击调节时间，观察指针变化。
- 分层闯关：提供基础、进阶、挑战三个层次的读钟练习。
- 错题再练：自动记录练习中的错题，便于针对性巩固。
- 手机适配：支持手机、平板和电脑浏览器访问。
- 答案隐藏：练习模式下不在钟面旁直接显示答案，避免影响学生作答。

## 使用方式

1. 下载本项目。
2. 用浏览器打开 `index.html`。
3. 课堂上可使用“教师演示”讲解，学生练习时切换到“分层闯关”。

## 建议场景

- 新授课后的巩固练习。
- 课堂投屏互动。
- 学生课后自主练习。
- 家校共育中的亲子读钟练习。
